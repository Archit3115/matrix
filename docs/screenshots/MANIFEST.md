# Screenshots

Every screenshot shows **orbit-shop**, a fictional demo project (an e-commerce backend made up for these pictures), plus its siblings **lumen-notes** (a small notes app) and their parent folder **demos**. The demo corpus was generated by a script. None of it is real code or data.

Capture setup: the Multiverse engine (`serve.py`) ran on 127.0.0.1 with a sandbox `MATRIX_HOME`. Headless Chrome was driven over the DevTools protocol at a 1600×1000 viewport, deviceScaleFactor 1. PNG text chunks are stripped. Files marked "near-lossless" had their low 2 bits per channel rounded off so they stay under 900 KB.
